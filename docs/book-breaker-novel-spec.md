# 宇界拆书工具 - 小说拆书专项规格

**版本**: v1.0  
**创建日期**: 2026-09-18  
**状态**: 需求确认，待开发  

---

## 一、核心目标

**一句话**：30分钟内，把一本厚小说拆成"故事脉络+人物档案+关键场景"，原文引用必须可追溯。

---

## 二、输入输出

### 2.1 输入
- 用户上传EPUB文件（本地解析）
- 不联网搜索，不依赖书名

### 2.2 输出文件（6个）
```
小说名/
├── 01-故事脉络.md      # 起承转合时间线 + 关键转折
├── 02-人物档案.md      # 每个人物：出场章节 + 关键事件 + 性格 + 原文引用
├── 03-关键场景.md      # 3-5个决定命运的场景 + 原文引用
├── 04-主题与隐喻.md    # 作者真正想表达什么
├── relations.png       # 人物关系图（可视化图片）
└── agent/
    ├── characters.jsonl  # 人物结构化数据（方便检索）
    └── quotes.jsonl     # 带出处的原文摘录
```

---

## 三、核心设计原则

| 原则 | 说明 |
|------|------|
| **原文必须带出处** | 每句话都要标注"第X章"或"p.XX" |
| **人物要有弧光** | 不只描述性格，要体现成长变化 |
| **关系图是图片** | 方便分享、插入笔记 |
| **全自动** | 不需要用户介入调整 |
| **30分钟完成** | 中等篇幅小说（10-30万字） |
