# 模块解耦检查清单

> 用于评估每个模块的独立性程度

---

## 检查项

### 1. 代码自包含性
- [ ] 模块包含自己的 types.ts
- [ ] 模块包含自己的 hooks/
- [ ] 模块包含自己的 utils/
- [ ] 不引用其他模块的代码（除了 registry）

### 2. Store 隔离
- [ ] 有自己的 store（不使用全局 layoutStore）
- [ ] 或者明确说明为什么需要共享 store

### 3. 组件依赖
- [ ] 不引用其他模块的组件
- [ ] 共享组件放在 src/shared/ 下
- [ ] 或模块内部复制必要的组件

### 4. 样式隔离
- [ ] 模块有自己的样式文件
- [ ] 不依赖全局 CSS 变量（除了设计令牌）
- [ ] 样式命名空间避免冲突

### 5. API 依赖
- [ ] 有自己的 API 调用层
- [ ] 不依赖其他模块的 API 函数
- [ ] 错误处理独立

### 6. 测试能力
- [ ] 可以单独运行单元测试
- [ ] 有 mock 数据支持
- [ ] 测试覆盖率 > 60%
